Radar, avalanche and roads

Live pages, opening in a new tab.

Forecasts come from Open-Meteo at fixed elevations for each location. Model snowfall is derived from precipitation and temperature, so treat it as guidance rather than measured depth. Snow level is estimated as 1,000 ft below the freezing level. Station depth is from NRCS SNOTEL and alerts from the National Weather Service (Washington sites only). The written outlook and morning forecast are generated by Claude each morning.
